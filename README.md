# 🧊 Smart Fridge & Beginner Recipe Guide

เว็บแอปพลิเคชันสำหรับจัดการวัตถุดิบในตู้เย็น ตรวจสอบวันหมดอายุ และหน้ากระดาษรายการคู่มือทำอาหารทีละขั้นตอนสำหรับมือใหม่

## ✨ ฟีเจอร์หลัก
- **Inventory Management & Expiry Checker:** เพิ่ม ลบ และตรวจสอบสถานะวันหมดอายุวัตถุดิบในตู้เย็นอัตโนมัติ (พร้อมระบบแจ้งเตือนของใกล้หมดอายุและหมดอายุ)
- **Dynamic Recipe Suggestion:** สุ่มเมนูอาหารไทยยอดนิยมพร้อมเช็ควัตถุดิบที่มีในตู้
- **Beginner Recipe Guide Card:** หน้ากระดาษรายการคู่มือทำอาหารอย่างละเอียด แสดงวัตถุดิบ ปริมาณเครื่องปรุงตามจริง และวิธีทำทีละขั้นตอนสำหรับมือใหม่
- **Local Storage:** บันทึกข้อมูลอัตโนมัติบนเบราว์เซอร์
